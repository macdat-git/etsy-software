# Sim Racing Flag Box

SimHub files and setup guide for the MacDat Sim Racing Flag Box.

## Download

**[Download the latest Flag Box files (.zip)](https://github.com/macdat-git/etsy-software/releases?q=flag-box)**: open the newest release and click the `.zip` under **Assets**.

You can also download individual files from this folder:

| File | What it is |
|---|---|
| `Quick Start Guide.docx` | Step-by-step SimHub setup with screenshots |
| `Any Game - Default Profile.ledsprofile` | Default flag display profile (RGB Matrix) for any game |

## Requirements

- Windows PC
- The latest version of [SimHub](https://www.simhubdash.com/)
- A free USB port or powered USB hub

## Quick setup

1. Install or update [SimHub](https://www.simhubdash.com/).
2. In SimHub, open **Arduino**.
3. Choose **Multiple Arduinos** if you have other Arduino devices, otherwise **Single Arduino**.
4. Connect the flag box by USB. After a few seconds it appears in the list.
5. If the display needs rotating, click the arrow next to **Flag Box** and change it in the device settings.
6. Click **Apply Changes**.
7. To load the included profile, open the **RGB Matrix** tab, then **Profiles Manager → Import profile**, and pick `Any Game - Default Profile.ledsprofile`.

See the Quick Start Guide for screenshots of each step.
